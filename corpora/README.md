# Corpora

Four stakeholder corpora, four groups. Each group **adopts one corpus** — the
discourse of one stakeholder in the AI-alignment debate — at the start of term
and works on it continuously, applying each week's concept and growing it from
the seed provided here.

**Start here:** read [`PROTOCOL.md`](PROTOCOL.md) — the shared construction rules
every corpus follows so the four stay comparable. The columns every manifest
uses are in [`manifest_schema.csv`](manifest_schema.csv).

| # | Stakeholder | Corpus | Seed provided |
|---|-------------|--------|---------------|
| 1 | Research | [Technical / scholarly work](1-cs/) | 182 papers (OpenAlex sweep, reproducible script) |
| 2 | Companies | [AI safety / company governance](2-company/) | **40 docs, full provenance** — the reference implementation |
| 3 | Government | [Policy / institutional](3-policy/) | 18 canonical instruments |
| 4 | Public | [Newspaper / public discourse](4-media/) | query + source frame (metadata only) |

**Weekly social pulse.** Each group also tracks its stakeholders' weekly posts on
**X / LinkedIn** — researchers, companies, officials, and journalists/public all
post there, so this captures the *current* discourse alongside the slower
documentary record. It is a weekly tracking lens within each corpus, not a
separate corpus.

Corpus 2 is finished and shows the target standard. Corpora 1 and 3 ship with
real reproducible seeds. Corpus 4 is the harder one — bulk text can't be
redistributed, so we provide the *method* and a small sample, and the group
builds it out.
